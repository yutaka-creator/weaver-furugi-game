古着屋ゲーム Ver.0.6 / 全国ランキング追加準備版 v9

【すぐ試せること】
1. index.html をブラウザで開く
2. タイトルの「ランキングを見る」からTOP10画面を確認
3. 5人を接客し、終了画面で初回ニックネームを登録
4. 次のプレイで最高売上を更新すると自動保存
※初期設定では「この端末内だけのテストランキング」です。全国共通ではありません。
※Safariのローカルファイル表示ではデータ保存が制限される場合があります。GitHub Pages等で確認してください。

【全国共通ランキングへ切替】
1. Supabaseにプロジェクトを作成
2. Authentication > Providers で Anonymous Sign-ins を有効化
3. supabase_setup.sql をSQL Editorで実行
4. js/ranking-config.js に Project URL と Publishable key（旧anon keyも可）を入力
   * service_role / Secret key はブラウザに絶対に置かないこと
5. GitHub Pagesに配置して確認

【仕様】
・TOP10と自分の順位/最高売上
・1匿名AuthユーザーIDにつき最高記録1件
・初回のみゲーム終了後の手動名前登録、その後は自己ベスト更新で自動登録
・同点は達成日時の早い方が上位（完全同時なら内部ID順）
・ニックネームは日本語・英数字で1〜10文字、個人情報の入力を控えるよう案内
・Supabaseテーブルはクライアントから直接読めず/書けず、RPC経由のみ
・サーバーで値域・文字種を検証し、記録更新の連続投稿を30秒制限
・匿名認証は端末/ブラウザのデータ削除や変更で引き継げません
・名前のNGワードはweaver_game_blocked_termsテーブルに管理者が登録できます
・SNS宣伝用の趣味のゲームなので、オンライン公開時は運用管理者による不適切名称の定期チェックも推奨

【注意】
・ブラウザ上のスコアは改造可能です。現在の対策ではスコア偽造を完全には防げません。
・Supabaseを接続しないと全国ランキングは動作しません。
・事業所サイトへのリンクは https://socialweavers.jp/ です。
・既存のゲーム商品19種類、客25人、効果音、結果画面宣伝カードを維持しました。
