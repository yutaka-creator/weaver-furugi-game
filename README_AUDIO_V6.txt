古着屋ゲーム Ver.0.6 音声追加版 v6

追加内容
- オリジナルの控えめなレトロ風BGM（Web Audio APIで合成、外部音源不要）
- 来店チャイム / 商品を持つ・置く / 交渉中 / 交渉成功 / 交渉失敗 / 販売成立 / レア商品 / 結果発表 / ボタン
- 画面上部の🔊/🔇でBGM・効果音をまとめてON/OFF
- iOS対策：ゲームスタートのタップ後にAudioContextを有効化

注意
- ブラウザでの実音テスト、iPhone/Androidでの検証は未実施。
- ブラウザや端末の音量設定、サイレントモードにより鳴らない場合があります。
- BGM/効果音はゲーム内のオリジナル音型で、既存曲のコピーではありません。
- Supabase全国ランキングは後続の開発工程です。
